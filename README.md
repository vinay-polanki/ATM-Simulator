# ATM Simulator

## Project Overview

This project is a simple ATM simulator built using Python that runs in the command line. It lets users perform common ATM tasks like checking their balance, withdrawing or depositing money, viewing recent transactions, and saving a mini statement to a text file.

It’s designed to help beginners understand how Python works with user input, conditions, loops, and file handling in a real-world scenario.

## Key Features
	•	Basic login system to start the session
	•	Check the current account balance at any time
	•	Withdraw (debit) or deposit (credit) money with proper balance checks
	•	Display a mini statement with recent activity
	•	Full transaction log with date, time, and updated balance
	•	Option to save the mini statement as a .txt file
	•	Easy-to-read and clean terminal interface# ATM-Simulator
